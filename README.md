# 🪪 Huwia ID - نظام إدارة وطباعة وفحص البطاقات التعريفية الذكية
### Smart Identification Card Management, Printing & Anti-Fraud Verification System

---

## 🌟 نظرة عامة على المشروع (Project Overview)

**Huwia ID (نظام هوية)** هو منصة برمجية متطورة وشاملة لإدارة دورة حياة البطاقات التعريفية للجامعات، الشركات، المؤسسات الحكومية، الفعاليات، والمستشفيات. يتيح النظام تصميم قوالب البطاقات بمرونة عالية، استيراد وإدارة بيانات حاملي البطاقات، المعالجة التلقائية للصور الشخصية، الطباعة الفردية والجماعية عالية الدقة، ونظام فحص وتحقق أمني ذكي لحظي عبر رموز الاستجابة السريعة المشفرة (Encrypted Signed QR Codes).

تم بناء النظام بالاعتماد على معمارية **Bedaya Modular Architecture** باستخدام **Laravel 13** و **Livewire 3/4** و **Filament Server-Driven UI** و **Tailwind CSS v4**.

## 🎯 المميزات الرئيسية للنظام (Key Features)

### 1. إدارة القوالب والتصميم (Template & Design Engine):
- دعم أبعاد البطاقات القياسية العالمية (CR80: 85.6mm × 54mm) بنوعيها: **أفقي (Landscape)** و **عمودي (Portrait)**.
- إمكانية تخصيص خلفية الوجه الأمامي والخلفي، ومواضع العناصر (الاسم، الرقم، الصورة، الشعار، الباركود، QR).
- إعدادات دقة الطباعة الاحترافية (300 DPI / 600 DPI) لضمان أعلى جودة على البطاقات البلاستيكية PVC.

### 2. إدارة حاملي الهويات (Cardholders & Profiles):
- سجلات شاملة للبيانات: الاسم ثنائي اللغة (عربي / إنجليزي)، الرقم القومي، الرقم الوظيفي/الأكاديمي، القسم/الكلية، فصيلة الدم، وتاريخ انتهاء الصلاحية.
- محرك معالجة وقص الصور الشخصية والتوقيعات الرقمية.
- استيراد جماعي للموظفين أو الطلاب من ملفات Excel/CSV.

### 3. محرك الطباعة ودفعات الإصدار (Print & Batch Engine):
- طباعة فردية مباشرة للبطاقات بطباعة الوجهين (Front & Back Duplex).
- طباعة جماعية في دفعات (Batch Printing) مع توليد أوراق قياس A4 تحتوي من 8 إلى 10 بطاقات مزودة بعلامات القص (Crop Marks).
- دعم الطابعات البلاستيكية المباشرة (Evolis, Zebra, Fargo, Datacard) عبر مخرجات PDF دقيقة بـ Vector Elements.

### 4. الفحص والتحقق الأمني الذكي (Smart Verification & Anti-Fraud):
- تشفير بيانات رمز الـ QR بتوقيع رقمي فريد (HMAC/Digital Signature) يمنع تزوير أو استنساخ البطاقات.
- شاشة فحص فورية تفاعلية بـ Livewire + WebRTC لمسح الـ QR Code مباشرة بكاميرا الهاتف أو أجهزة قراءة الباركود.
- فحص حالة البطاقة الفورية: (نشطة وموثقة ✅، منتهية الصلاحية ⚠️، ملغاة أو مفقودة ❌، غير معروفة 🚫).
- سجل كامل لعمليات الفحص مع حفظ وقت الفحص، الموقع الجغرافي، ومعرف جهاز الفحص.

## 🏛️ الهيكلية المقترحة للمشروع (Modular Architecture)

يتم تقسيم النظام إلى موديولات مستقلة داخل مجلد `Packages/`:

```text
Packages/
├── Common/              # الإعدادات العامة، الفروع، التراخيص
├── CardEngine/          # محرك القوالب والأبعاد والتنسيقات الرسومية
├── IdentityModule/      # إدارة حاملي البطاقات، استيراد البيانات، ومعالجة الصور
├── CardIssuance/        # دورة حياة البطاقات، أرقام الإصدار، ودفعات الطباعة
├── VerificationModule/  # محرك الفحص الذكي، التحقق الأمني، وسجلات المسح
└── Providers/           # موفرو الخدمات والربط المركزي (BedayaServiceProvider)
```

## 🗄️ ملخص هيكل قاعدة البيانات المقترح (Database Schema Overview)

1. **`organizations` / `departments`**: الجهات والأقسام التابعة لها البطاقات.
2. **`card_templates`**: قوالب البطاقات (الأبعاد، التوجه، صور الخلفية، مساحات العناصر JSON).
3. **`cardholders`**: بيانات الأشخاص حاملي البطاقات (الاسم، الهوية، المنصب، الصورة، التوقيع).
4. **`cards`**: سجل البطاقات الفعلي (`card_uid` فريد، `qr_payload`، الحالة، تاريخ الإصدار والانتهاء، عدد مرات الطباعة).
5. **`card_batches`**: سجل دفعات الطباعة المجمعة وتاريخها.
6. **`card_reissues`**: طلبات إعادة الإصدار وأسباب الفقدان أو التلف.
7. **`verification_logs`**: سجلات عمليات المسح والفحص الأمني مع الموقع والنتيجة.

## 📅 خطة العمل المرحلية (Phased Roadmap)

* **المرحلة 1: التأسيس والتجهيز الهيكلي (Setup & Architecture)**
  - ضبط الحزم وتحديث ملفات التكوين وقواعد البيانات.
* **المرحلة 2: محرك القوالب والبيانات (Templates & Cardholders)**
  - بناء نماذج إدارة البيانات واستيراد ملفات Excel ومعالجة الصور.
* **المرحلة 3: دورة حياة البطاقات ومحرك الطباعة (Lifecycle & Print Engine)**
  - توليد الرموز الفريدة والباركود والـ QR وتجهيز قوالب الطباعة الفردية والجماعية.
* **المرحلة 4: بوابة الفحص المباشر (Livewire Verification Scanner)**
  - بناء واجهة مسح الـ QR بالكاميرا مع الربط اللحظي بسيرفر Reverb.
* **المرحلة 5: التدقيق، الأمان، وتجهيز الإنتاج (Security & Deployment)**
  - تدقيق الصلاحيات وسجلات التتبع وربط طابور المهام بملف `laravel-worker.conf`.
