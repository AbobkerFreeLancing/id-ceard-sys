## 🎯 المعايير التقنية الصارمة المعتمدة:
1. **Livewire 3/4**: الاعتماد الكامل على التفاعل اللحظي دون إعادة تحميل الصفحة.
2. **Tailwind CSS v4**: استخدام أحدث فئات التصميم العصرية، الزجاجية (Glassmorphism)، والتدرجات اللونية المتناسقة.
3. **Zero JavaScript Spaghetti**: استخدام Alpine.js فقط للحالات البسيطة في المتصفح، مع إسناد منطق التحقق للباك إند.
4. **التوطين العربي الكامل**: جميع النصوص تستدعى من ملفات الترجمة `__('idcard::idcard....')` و `__('backend....')`.
